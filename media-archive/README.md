# Media archive

`v1-site-images/` holds every image the theme used before the August 2026 media refresh.
They came from the 2017 EverWeb site (max source width 874px) and are kept so any
replacement can be reverted.

To restore one, copy it back over the file of the same name in
`dynamic-theme/assets/img/`.

Nothing in this folder is served. It sits outside the theme so it is not deployed.
